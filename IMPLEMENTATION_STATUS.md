# Feature status

## Implemented in source
- Multiple period entries stored locally
- Period start/end date validation
- Flow, symptoms and notes
- Multiple conception/sex log entries with optional method and notes
- Overview with next-period and rough fertile-window estimates when cycle length is supplied
- Delete individual entries
- Export JSON backup through Android share sheet
- Cloud-build workflow using GitHub Actions

## Not implemented
- Couple invitation code and shared workspace
- Cloud database sync / conflict handling
- Import/restore backup
- Notifications
- App PIN/biometric lock
- Medical validation or device testing

## Privacy warning
This is a personal tracking starter, not a certified medical product. Keep exported backups private. Calendar estimates cannot confirm ovulation or guarantee pregnancy.
